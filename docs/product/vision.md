# 产品愿景

Security Agent Suite 的目标不是做一个“什么都能回答的安全聊天机器人”，而是把五类可重复的安全工作转换为五个可独立调用、可组合、可审计的生产单元。

## 目标效果

```text
结构化任务输入
  → 明确授权和工具集合
  → 隔离运行
  → 确定性工具产出事实
  → Agent 关联、解释与提出建议
  → 证据化结构结果
  → 人工审批或报告交付
```

## 产品原则

1. **独立调用优先**：每个 Agent 有稳定 ID、输入、输出和权限；
2. **证据优先**：安全结论的价值来自可复核事实，不来自模型语气；
3. **工具优先**：模型做规划和解释，解析、查询、计算和验证由工具完成；
4. **最小权限**：每个 Agent 只看见完成任务所需能力；
5. **人工掌控高风险动作**：模型不能批准自己的行为；
6. **可组合但不隐式越权**：跨 Agent 流程由显式 Workflow 控制；
7. **核心 Go，工具多语言**：长期控制逻辑用 Go，成熟安全工具通过服务边界复用。
