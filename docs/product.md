# Product

## Scope
A reference implementation for packaging five independently callable cybersecurity agents behind a Go control plane: traffic analysis, event triage, attack-path validation, compliance query, and security reporting.

## First release result
The alpha release provides runnable Mock-mode control-plane behavior, contracts, agent declarations, policy gates, persistence baselines, and an agent-compose adapter.

## Not included
No customer data source, production HA storage, automatic response, unrestricted active testing, or claim of real Agent acceptance. See [`PROJECT_STATUS.md`](../PROJECT_STATUS.md) for evidence and limits.
