# ADR-0005：文件存储只用于单实例起步

- 状态：Accepted
- 日期：2026-09-03

## 决策

当前用 JSON 文件保存 Run、JSONL 保存审计、文件系统保存 Artifact，以便零外部依赖运行。生产阶段迁移到 PostgreSQL + S3/MinIO。

## 限制

- 当前只能安全运行单写实例；
- 不提供跨节点锁、租约、事务队列和 HA；
- 审计文件不是防篡改存储；
- 大规模列表和统计效率有限。

## 迁移要求

Store 和 Artifact 已通过接口隔离。M7 前完成 PostgreSQL、对象存储、迁移工具、备份恢复和一致性测试。
