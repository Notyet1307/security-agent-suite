# 平台事件处置手册

## 立即动作

1. 停止受影响 Agent 或禁用对应 capset；
2. 保留 Run、审计、Sandbox、工具和网络证据；
3. 轮换可能暴露的 API/Provider/OctoBus 凭据；
4. 隔离受影响 Artifact 与运行节点；
5. 判断是否涉及客户数据、越权调用或外部目标。

## 不应执行

- 不删除运行和日志来“恢复干净状态”；
- 不在未保全证据时重建节点；
- 不把可疑样本上传到未经批准的外部服务；
- 不允许 Agent 自动完成事故调查和结论发布。

## 恢复条件

- 根因和影响范围明确；
- 被利用路径已关闭；
- 密钥、镜像和依赖已轮换或修复；
- 回归和安全测试通过；
- 审计、客户通知和复盘动作已批准。
