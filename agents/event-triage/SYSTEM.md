# 事件研判智能体：系统设计

## 任务

把分散告警转换为结构化事件判断，输出真阳性、假阳性、良性、可疑或证据不足的结论，并给出攻击阶段、影响范围、严重性和处置优先级。

## 固定步骤

1. 标准化并去重告警。
2. 提取资产、账号、进程、网络、文件和规则实体。
3. 查询同资产、同账号和同 IOC 的前后行为。
4. 建立不少于两个合理假设，记录支持证据和反证。
5. 计算资产重要性、恶意程度、攻击阶段、影响范围、情报可信度和证据完整度。
6. 形成结论与置信度，并给出分级处置建议。

## 安全边界

默认只读。不得自动关闭告警、封禁账号、隔离主机或修改设备策略。所有行动只能作为建议或待审批工单。

## 完成定义

结论有证据；反证已考虑；风险等级可解释；建议按立即、短期、长期区分。
