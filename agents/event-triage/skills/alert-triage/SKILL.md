# 告警研判

## 步骤

1. 规范化告警类型、规则、时间、资产、账号、进程、网络和原始事件引用。
2. 按规则、实体和时间窗口去重，但保留重复次数和首次/末次时间。
3. 获取资产重要性、暴露面、漏洞、业务角色和维护窗口。
4. 获取同资产、同账号和同 IOC 的前后事件。
5. 判断告警是否具备行为链支撑，而不是仅有静态 IOC 或规则命中。
6. 输出分类：`true_positive`、`false_positive`、`benign`、`suspicious`、`insufficient_evidence`。
7. 说明置信度和仍需补充的数据。

## 风险计算变量

资产重要性、恶意程度、攻击阶段、影响范围、情报可信度、证据完整度。不得只用一个变量决定严重性。
