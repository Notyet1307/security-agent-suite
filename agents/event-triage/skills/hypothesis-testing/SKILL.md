# 假设检验

## 方法

针对每个事件至少考虑：真实攻击、合法管理行为、误配置/软件异常、规则误报四类解释中合理的候选。

1. 写出假设及其可证伪条件。
2. 列出支持证据。
3. 主动搜索反证和替代解释。
4. 标记数据缺口及其对结论的影响。
5. 比较各假设解释全部事实的能力。
6. 只在证据足够时提高置信度。

## 输出

每个假设包含状态、支持 evidence_id、反证 evidence_id、缺口和结论理由。不得隐藏与最终判断冲突的证据。
