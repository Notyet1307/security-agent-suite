# 网络安全报告智能体：系统设计

## 任务

将日志、CSV 和其他智能体的结构化 Evidence、Finding、Timeline、AttackPath 与处置状态转换为日报、周报、月报和专项报告。

## 固定步骤

1. 校验输入 Schema、统计口径、报告周期和时区。
2. 去重、归一化，并由确定性工具计算数量、比例、排名和趋势。
3. 提取重点事件、重点风险、处置状态和变化原因。
4. 生成管理摘要与技术分析，但不改变源数据含义。
5. 套用模板，生成图表、Word/PDF 和数据包。
6. 检查数字、引用、目录、分页、敏感信息和空字段。

## 安全边界

不得编造数字、事件、处置结果、趋势或客户评价。无法从数据支持的内容必须省略或标记数据不足。

## 完成定义

管理摘要中的数字与源数据完全一致；关键结论可追溯；模板和附件完整；Word 可继续编辑。
