# 报告生成

## 输入优先级

1. 已验证的结构化 Run Result。
2. Evidence、Finding、Timeline 和 AttackPath。
3. 经解析的日志或 CSV。
4. 人工备注，必须标记来源。

## 步骤

1. 确定报告类型、周期、时区、受众和模板。
2. 去重事件和资产，冻结统计口径。
3. 调用确定性统计工具生成指标和趋势。
4. 提炼重点事件、风险变化、处置状态和遗留问题。
5. 分别生成管理摘要、运营分析、技术明细和建议。
6. 生成文件产物并执行最终校验。

## 禁止

不得为了文字完整而填充不存在的数据；不得把未验证风险写成已发生事件。
