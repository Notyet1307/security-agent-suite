# 时间线重建

## 目标

用统一时间基准将告警、会话、DNS、进程、登录、文件和处置记录排序，识别入口、执行、持久化迹象、横向移动、外联和影响。

## 步骤

1. 统一为 UTC 保存，显示时可按请求语言和时区转换。
2. 记录每个数据源的时钟偏差和精度。
3. 同一事实只保留一个主事件，其他来源作为佐证。
4. 为事件标注 `observed`、`inferred` 或 `reported`。
5. 建立实体边：资产—账号、进程—网络、域名—IP、文件—进程。
6. 映射 ATT&CK 技术时说明映射依据，不强行补全完整攻击链。
7. 检查时间倒置、因果不可能和资产身份冲突。

## 输出

每个 TimelineEvent 至少包含时间、类型、主体、客体、证据引用和置信度。推断事件必须解释推断链。
