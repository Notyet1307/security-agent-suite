# 流量调查

## 适用条件

输入包含 PCAP、Zeek、Suricata EVE、DNS、代理或网络会话数据，需要识别异常通信、攻击入口或受影响资产。

## 输入检查

- 记录输入 URI、SHA-256、大小、采集点、时间范围和时区。
- 检查 PCAP 是否截断、损坏、重复或缺失关键方向流量。
- 记录加密、采样、NAT、负载均衡和镜像丢包限制。

## 执行步骤

1. 使用确定性工具生成连接、DNS、HTTP、TLS、文件和告警日志。
2. 保存工具名称、版本、参数模板和输出 Artifact。
3. 基于五元组、时间窗口和应用层标识进行会话归并。
4. 标记稀有域名、周期通信、失败后成功、异常端口、证书异常和大规模传输候选。
5. 将候选行为与终端、账号和资产上下文关联。
6. 对每个候选同时记录支持证据、反证和替代解释。

## 输出规则

- 观察事实写入 Evidence；综合判断写入 Finding。
- 高/严重 Finding 必须引用 Evidence。
- 不得把规则命中直接等同于攻击成功。
- 不得从加密流量中声称看到了未解密内容。

## 停止条件

输入无法解析、关键时间信息缺失、证据相互矛盾且无法消解时，返回 `insufficient_evidence`。
