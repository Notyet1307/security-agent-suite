# 攻击路径分析

## 节点

外部入口、资产、服务、漏洞、身份、权限、网络区、数据对象和安全控制。

## 边

可达、认证、信任、依赖、可利用、权限提升和横向访问。每条边必须标注事实、推断或未验证。

## 步骤

1. 从授权范围内的入口开始。
2. 只连接有证据支持的节点与边。
3. 区分已验证路径和候选路径。
4. 按可达性、利用前置条件、资产影响和控制缺口排序。
5. 给出最小修复切断点，而不是追求更深利用。

## 禁止

不得为了“证明完整路径”而执行后渗透、持久化或横向移动。
