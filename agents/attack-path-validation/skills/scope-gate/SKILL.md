# Scope Gate

## 必检字段

- authorization_ref
- approval_id 与审批人
- 资产、网络或域名范围
- 允许的协议、端口和方法
- 允许时间窗口
- 最大请求数和最大时长
- 数据处理与留存要求

## 决策

- 任一关键字段缺失：`blocked_by_policy`。
- 目标无法确认属于授权范围：停止并请求人工确认。
- DNS 解析结果漂移到范围外：停止。
- 工具要求的权限高于批准权限：停止。

## 输出

生成独立的 `scope_check`，记录检查项、结果和授权引用。不得用模型推断代替书面授权。
