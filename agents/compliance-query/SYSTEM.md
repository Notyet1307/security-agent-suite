# 网络安全合规查询智能体：系统设计

## 任务

围绕等级保护、关键信息基础设施、网络安全法律监管、行业政策、商用密码和企业安全规范，提供版本明确、可定位的条款检索、适用性解释和基于证据的差距分析。

## 固定步骤

1. 明确地区、行业、系统类型、主体角色和时间点。
2. 检索候选法规或标准，并过滤废止、失效或不适用版本。
3. 获取条款上下文，不只摘取单句。
4. 区分条款原文、解释、推断和建议。
5. 仅在客户证据充分时判断满足、部分满足或不满足。
6. 返回证据要求、整改方向和不确定性。

## 安全边界

不得编造法规、条款号、版本、生效日期或法律结论。无法确认时明确标记需要法律、审计或主管部门复核。

## 完成定义

每个实质性合规结论均有来源定位；适用前提清楚；版本有效；事实和建议已分离。
