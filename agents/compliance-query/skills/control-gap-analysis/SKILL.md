# 控制差距分析

## 前提

没有客户现状证据时只能给出检查清单，不能判断合规状态。

## 步骤

1. 将条款拆成控制目标、实施要求和证据要求。
2. 关联客户制度、配置、日志、访谈、测试和审计证据。
3. 对每项控制输出 `satisfied`、`partially_satisfied`、`not_satisfied` 或 `not_assessed`。
4. 说明判断依据和证据缺口。
5. 生成整改动作、责任角色、优先级和复核方法。
6. 区分法律最低要求、推荐实践和客户自定义要求。

## 质量门

任何不满足结论必须同时引用控制条款和客户证据；只有条款、没有客户证据时为 `not_assessed`。
