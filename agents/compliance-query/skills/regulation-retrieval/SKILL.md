# 法规标准检索

## 查询变量

地区、行业、主体角色、系统类型、数据类型、安全等级、时间点和问题类型。

## 步骤

1. 把自然语言问题拆成适用性变量。
2. 检索候选文件，优先权威来源和正式版本。
3. 检查发布日期、生效日期、废止状态、修订关系和适用范围。
4. 获取条款上下文、定义和例外。
5. 记录文档名、版本、章节、条款号、来源 URI 和检索时间。
6. 返回最相关依据，并说明未覆盖范围。

## 禁止

不得根据记忆生成条款；不得把草案、解读或新闻当成正式强制要求。
